# Weather App

A simple and responsive weather application built with HTML, CSS, and JavaScript that fetches real-time weather data.

## Features

* **Search by City:** Enter any city name to view current weather details.
* **Live Weather Data:** Displays temperature, humidity, and wind speed.
* **Error Handling:** Shows a friendly error message if the city name is invalid.
* **Responsive Design:** Works smoothly on mobile and desktop screens.

## Built With

* **HTML5:** Page structure and layout
* **CSS3:** Styling, layout, and responsive design
* **JavaScript (ES6):** DOM manipulation and API fetching
* **API:** [OpenWeatherMap API](https://openweathermap.org/)

## Getting Started

To run this project locally, follow these simple steps:

### Prerequisites

You need a web browser (like Chrome or Firefox) and a code editor (like VS Code). You will also need a free API key from [OpenWeatherMap](https://openweathermap.org/).

### Installation

1. **Clone the repository** (or download the ZIP file):
   ```bash
   git clone https://github.com
   ```
2. **Open the project folder** in your code editor.
3. **Add your API key:**
   Open your `script.js` file and replace `"YOUR_API_KEY"` with your actual OpenWeatherMap API key:
   ```javascript
   const apiKey = "YOUR_API_KEY";
   ```
4. **Run the app:**
   Open `index.html` directly in your browser, or use a live server extension (like the Live Server extension in VS Code) for the best development experience.

## Usage

1. Type the name of a city into the search input box.
2. Click the **Search** button (or press Enter) to fetch the weather.
3. View the updated temperature, humidity, and conditions on the screen.
